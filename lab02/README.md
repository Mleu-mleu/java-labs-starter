# Лабораторная работа 2: Классы и инкапсуляция

Условие: [`assignments/lab02-domain-model.md`](../assignments/lab02-domain-model.md).

Из корня репозитория запустите:

```bash
./mvnw -pl lab02 test
```

Windows PowerShell: `.\\mvnw.cmd -pl lab02 test`.

Основной код размещайте в `src/main/java/edu/course/lab02/`, тесты — в `src/test/java/edu/course/lab02/`. В начале каждого Java-файла укажите `package edu.course.lab02;`.

Модуль независим от остальных лабораторных. Если нужны модели из предыдущей работы, перенесите и при необходимости адаптируйте только нужные классы в этот модуль. Начальная успешная сборка не является выполнением задания: создайте реализацию и собственные тесты по условию.

### BankAccount
1. Баланс не может быть отрицательным ни в один момент времени.
2. Начальный баланс задаётся в конструкторе и не может быть отрицательным.
3. Пополнение принимает только положительную сумму.
4. Списание принимает только положительную сумму и не больше текущего баланса.
5. Баланс читается через getBalance, но не может быть изменён напрямую — setter отсутствует.

### ProjectTask
1. id не null и не пустой.
2. title не null и не пустой.
3. estimatedHours > 0.
4. status не null.
5. id и title неизменяемы после создания (final).
6. estimatedHours может только увеличиваться через addHours, никогда не уменьшаться.
7. status меняется только методом changeStatus.
